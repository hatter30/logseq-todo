토큰 만들기
  1. GitHub 설정 → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access에서 Logseq 레포 하나만 선택
  3. Permissions → Contents를 Read and write로
토큰은 이 기기 브라우저에만 저장되고 GitHub 외에는 보내지 않아요.
Logseq config.edn의 :journal/file-name-format과 같게. 기본값 yyyy_MM_dd
0이면 전체. 365로 하면 최근 1년 저널과 모든 페이지만 받아요
